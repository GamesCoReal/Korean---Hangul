# 🇰🇷 Hangul Quest

**Learn Korean one step at a time.**

Hangul Quest is an interactive Korean learning application designed to teach users how to recognize, pronounce, construct, and write Korean characters (Hangul).

The application uses lessons, flashcards, building exercises, writing practice, and tests to help users gradually learn the Korean alphabet.

## Features

### 1. Lessons
- Organized learning progression.
- Six introductory lessons.
- Lessons unlock sequentially.
- Each lesson contains specific Korean characters and their associated sounds.
- Complete lesson tests to unlock the next lesson.

### 2. Flashcards
- Randomized Korean character questions.
- Multiple-choice answers.
- Pronunciation using text-to-speech.
- Immediate answer feedback.
- Tracks correct answers and learning streaks.

### 3. Building Blocks
- Learn how Korean characters are constructed.
- Break syllables into individual consonants and vowels.
- Practice assembling character sequences.
- Randomized exercises.
- Supports Korean-to-English and English-to-Korean exercises.

### 4. Writing Practice
- Interactive drawing canvas.
- Draw Korean characters using a mouse or touchscreen.
- Character and pronunciation prompts.
- Automatic drawing similarity evaluation.
- Three successful writing attempts required per character.

### 5. Lesson Tests
- Tests combine character recognition and building exercises.
- Questions are randomized.
- Requires a minimum score of 70% to pass.
- Passing unlocks the next lesson.
- Previously completed tests can be retaken.

### 6. Progress Tracking
- Tracks individual character progress.
- Records correct answers, total attempts, and streaks.
- Tracks flashcard, building, and writing progress separately.
- Displays completed and incomplete characters.
- Saves progress automatically using browser local storage.

## Learning Progression

| Lesson | Content |
|---|---|
| Consonants 1 | First seven consonants |
| Consonants 2 | Remaining basic consonants |
| Vowels 1 | Basic vowels |
| Vowels 2 | Remaining basic vowels |
| Syllable Blocks 1 | Combining consonants and vowels |
| Reading 1 | Reading simple Korean syllables |

## Requirements

- Modern web browser.
- JavaScript enabled.
- Local storage enabled.
- Internet connection is not required for the core application.

## Installation and Usage

1. Download or clone the project.
2. Open the HTML file in a modern web browser.
3. Select a lesson.
4. Complete flashcard and building exercises.
5. Practice writing characters.
6. Pass the lesson test to unlock the next lesson.

No server, package manager, or external JavaScript dependencies are required.
